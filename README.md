# Sabores Variados

Proyecto web para un restaurante ficticio desarrollado como parte de un proyecto académico.

## Versión actual

**Versión 1.0 - Diseño base**

Esta primera versión contiene la estructura y el diseño inicial de la página web:

- Página principal
- Menú de platos destacados
- Sección de información sobre el restaurante
- Formulario de contacto
- Diseño responsive utilizando Bootstrap
- Imágenes y estilos propios

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5
